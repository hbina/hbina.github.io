Now that we have LLMs, there are several things that I think is true.

## Code is Commodity

This is a bit more complicated than just "it does not matter how something is written or how something is done".
I think this is only true specifically for business logic but not foundational software.

I think something that something like databases and Linux will continue to be written "carefully" and every line of code needs to be vetted.

This is not true for websites, GUI applications, analysis scripts, etc
I think the pressure to deliver features will cause the code written at this level to simply grow exponentially.

Because a person can instruct the LLM to implement the high level concept, the generated code itself is pretty much worth nothing.
If pressing that button does that it does, then that is all that matters.
